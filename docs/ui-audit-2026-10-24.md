## Gaps against the references

Reference images: Apple Maps place card (photo hero, action pills, About), Apple Maps Places list, Google Maps search list (row cards with thumbnails, rating and category), Google Maps place panel (hero, action row, Quick facts).

1. **Search results were plain rows.** Place results used `UnifiedCard`: a 72px thumbnail, title, a subtitle, and an optional rating. There was no selected state and no action bar on the result itself. Fixed in this change with `ContextCard` (see below).
2. **No photo hero for the selected place.** Fixed: `EntityDetail` uses a 16:9 hero (max 240px). Selecting a search card opens it.
3. **Quick facts are not a row pattern.** Fixed: `QuickFacts` rows sit under the action bar, before «Опис».
4. **Honest data is good.** Ratings show only when a source exists. Demo ratings carry «Демо». No new issue found.
5. **Category colors.** Pins and orbs use `CITY_PLACE_CATEGORY_COLORS`. The reference apps use one accent for all results, which this app keeps by category. This is a deliberate difference, not a gap.
